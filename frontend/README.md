# Digital Logbook — Frontend

This folder contains the frontend of the Digital Logbook web application.

The frontend is built using React and JavaScript (JSX). It is responsible for the user interface, page navigation, and client-side presentation.

Backend/API functionality will be integrated later.

---

## Tech Stack

- React
- JavaScript
- JSX
- Vite
- React Router
- CSS

### Important

This project uses **JavaScript + JSX**.

Do not introduce TypeScript into the frontend.

Use:

- `.js`
- `.jsx`

Do not use:

- `.ts`
- `.tsx`
